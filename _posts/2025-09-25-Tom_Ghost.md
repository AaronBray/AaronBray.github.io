Now that we have the PGP key in a text file on our machine lets use john to create a hash

{% endhighlight bash %}


Now that we have a hash file we can run it against our trusty 'rockyou' text file

{% highlight bash %}

# LESSONS LEARNED:
This machine was exploited due to a known LFI/file read vulnerability in Apache Tomcat
We were able to retrieve a username and password due to weak coding practices
To avoid LFI and many other vulnerabilities, follow secure programming habits and never trust user input. 
If you need to include local files, use a whitelist of allowed file names and locations.

Further reading on this vulnerability:
[AJP File Read/Inclusion in Apache Tomcat](https://access.redhat.com/solutions/4851251)
