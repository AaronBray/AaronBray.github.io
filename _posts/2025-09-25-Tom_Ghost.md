TRYHACKME CTF WRITE-UP
[tryhackme.com/room/tomghost](https://tryhackme.com/room/tomghost)




We start off with an nmap scan to enumerate the open ports and serviceS

{% highlight bash %}
nmap -sCV x.x.x.x
{% endhighlight bash %}

![img]({{ '/assets/images/tomghost/1-ghost.png' | relative_url }}){: .center-image }



We can see:
{% highlight bash %}
  PORT     STATE SERVICE    VERSION
    22/tcp   open  ssh        OpenSSH 7.2p2 Ubuntu 4ubuntu2.8 (Ubuntu Linux; protocol 2.0)
    53/tcp   open  tcpwrapped
    8009/tcp open  ajp13      Apache Jserv (Protocol v1.3)
    8080/tcp open  http       Apache Tomcat 9.0.30
    Service Info: OS: Linux; CPE: cpe:/o:linux:linux_kernel
{% endhighlight bash %}

Lets not get overwhelmed
Lets take this step by step...

We can see:
-SSH is open - As we dont have credentials to test now we will keep this in mind for later
-Port 53 is running a service called tcpwrapped - This is an ACL running on a firewall, nothing really to bypass here, 
-Web server is running on port 8080 not 80 - notated for scans and enumeration
-ajp13 apache Jserv & Apache Tomcat 9.0.30 are running

**The system didn't like using 'pgp' so we will use the 'gpg' substitute from here on out instead**

As you can see above we get an error saying ther is no secret key to be found 


Lets use the command below to import the private key 

{% highlight bash %}

{% endhighlight bash %}



![img]({{ '/assets/images/tomghost/10-ghost.png' | relative_url }}){: .center-image }


Lets now try again to decrypt the file

{% highlight bash %}

{% endhighlight bash %}

![img]({{ '/assets/images/tomghost/11-ghost.png' | relative_url }}){: .center-image }


We now get an error output stating that we need the secret key for user 'tryhackme'
*Note this is different from the private PGP key file

We only show users merlin and skyfuck
Lets use hydra to see if we can bruteforce the secret key for the user tryhackme

First Lets copy and save the PGP private key into a text file on our machine
Copy the entire file 

{% highlight bash %}
Copy everything below:
----BEGIN PGP PRIVATE KEY BLOCK-----
Version: BCPG v1.63
<PGP KEY>
-----END PGP PRIVATE KEY BLOCK-----
{% endhighlight bash %}


Now that we have the PGP key in a text file on our machine lets use john to create a hash 


{% highlight bash %}
gpg2john pgp_key > pgp_hash
{% endhighlight bash %}


Now that we have a hash file we can run it against our trusty rockyou text file

{% highlight bash %}
john --wordlist=/usr/share/wordlists/rockyou.txt pgp_hash 
{% endhighlight bash %}



![img]({{ '/assets/images/tomghost/12-ghost.png' | relative_url }}){: .center-image }


In a few seconds we have the cracked hash for the user tryhackme!
